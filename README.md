# Password Generator

## Descrizione

Un semplice generatore di password.  
Le genera soltanto premendo il tasto "CREA".  
Non ha ancora la possibilità di poter scegliere i parametri dall'interfaccia.  
Per questo ho già scelto di default il minimo sindacale, ovvero una lunghezza di 8 caratteri che include Minuscole, Maiuscole, Numeri e Simboli.
